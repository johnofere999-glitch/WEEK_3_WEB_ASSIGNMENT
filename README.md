# Personal Budget & Expense Tracker

A modern, clean, and responsive visual layout for a Personal Budget & Expense Tracker application built with semantic HTML5 and modern CSS3.

## Overview
This week's focus was on transforming the raw static structure into a fully styled visual interface using an intentional color palette, modern typography, proper CSS Box Model mechanics, and customized form/table styling.

## Features & Implementation Details

### 1. Intentional Color Palette
- **Primary Accent (`#4318ff`)**: Used for action buttons, focus highlights, and table headers to create a cohesive brand identity.
- **Background (`#f4f7fe`)**: A subtle light slate background that makes white card containers pop.
- **Text & Elements (`#2b3674`)**: High-contrast deep navy blue used for headings and body text to maximize legibility.

### 2. Custom Typography
- Embedded **Poppins** (headings & buttons) and **Inter** (body, forms, & tables) via Google Fonts.
- Formatted clear typographical hierarchy with intentional line heights, font weights, and font-size scaling.

### 3. Box Model & Card Layout
- **Container Cards**: Utilized CSS Box Model principles (`margin`, `padding`, `border`, and `border-radius`) to turn the Header, Form, and Table into distinct visual cards.
- **Elevation**: Applied subtle box shadows to create a modern floating card layout.

### 4. Table & Form Styling
- **Form Controls**: Added consistent inner padding, rounded borders, and custom focus states (`:focus`).
- **Table Design**: Configured styled headers, row padding, hover states, and alternating row colors (`nth-child(even)`).
